# HANi 1.1.0.4

## 界面调整

- “一键更新”在工具栏中以图标显示；已下载页完整的九项操作按既定顺序排列，更新为第八项、读取下载目录为第九项。窄屏溢出菜单沿用同一顺序，更新操作不再固定在“更多”按钮左侧。
- 非下载页的单视频卡片在封面内侧左上角显示下载完成图标。首页、订阅、喜爱、稍后再看、搜索、观看历史、播放清单、视频详情及相关推荐统一使用共享下载状态。
- 补齐首页轮播与队列、本地历史、详情全集列表、月份预览、打卡视频项和创作中心上传中卡片；无视频编号或没有完成下载记录时不显示图标。
- “已播放”标记保持右上角位置；创作中心审核角标移至右上角，避免与下载图标重合。

## 安装

下载附件 `HANi-1.1.0.4-arm64-v8a.apk`，适用于 arm64-v8a Android 设备。应用包名保持 `com.kelaner.hani`，使用项目既有发布签名，可覆盖升级 HANi；与原版 Han1meViewer 共存。

`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。

## 验证

Debug 构建、23 项单元测试及 Android API 35 模拟器上的 15 项仪器测试通过。检查覆盖九项操作的宽窄屏顺序、纯图标工具栏、160dp 视频卡片双标记互不重叠、下载完成记录及不同画质切换、七类独立封面下载状态的新增和删除。

完整 Lint 已运行，仍存在项目原有的两项英日语排序文案翻译缺失错误；详细页面覆盖与验证边界见仓库的 `artifacts/verification-1.1.0.4.md`。未逐个登录线上账号执行全站端到端测试。

## 状态说明

“已下载”依据本地下载数据库中的完成记录，与下载库保持一致；手动删除媒体文件后，应通过已有下载维护功能清理失效记录。本次不改变下载引擎或文件完整性判断规则。
